Перенос на сервер БЕЗ интернета
================================

На флешку — эта папка ofline плюс отдельно файлы T-lite (см. docs/перенос-t-lite-на-офлайн-сервер.md).
Модель Ollama в Docker-образ НЕ входит.

1. Скопируйте из ofline:
   - rewriter-images.tar.gz
   - docker-compose.yml
   - load.sh
   - КАК_ЗАПУСТИТЬ.txt

2. На сервере (Linux, Docker уже установлен):

   cd /opt/rewriter-ofline
   chmod +x load.sh
   ./load.sh

   Или: gzip -dc rewriter-images.tar.gz | docker load && docker compose up -d

   Не распаковывайте rewriter-images.tar.gz через tar/архиватор —
   это сжатый Docker-образ, его нужно грузить командой docker load.

3. Ollama на сервере (уже прописано в docker-compose.yml):
   LLM_BASE_URL=http://192.168.254.20:11434
   LLM_REWRITE_MODEL=t-tech/T-lite-it-2.1:q4_K_M
   LLM_PROOFREAD_MODEL=t-tech/T-lite-it-2.1:q4_K_M

   Сначала импортируйте T-lite в Ollama, иначе сайт не обработает текст.
   Контейнер ходит на LLM_BASE_URL. Если Ollama на той же машине,
   что и Docker, и слушает только 127.0.0.1 — либо
   OLLAMA_HOST=0.0.0.0:11434, либо host.docker.internal
   (в compose уже есть extra_hosts).

Словарь терминов хранится в папке data рядом с compose.

Не запускайте "docker compose up --build".

Сайт: http://IP-СЕРВЕРА:8181
