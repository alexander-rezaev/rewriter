# Рерайтер

Локальный сайт переписывает текст и проверяет его через модель в Ollama или llama.cpp. Регистрация не нужна. Сайт открывается в браузере на порту 8181.

Модель не входит в проект. По умолчанию для переписывания и проверки используется `t-tech/T-lite-it-2.1:q4_K_M`.

## Как пользоваться

Откройте http://localhost:8181. Текст слева, результат справа.

Режимы:

- **Переписать** — пересказывает текст в выбранном стиле и сохраняет факты, числа, даты, шифры и названия.
- **Проверить орфографию и грамматику** — правит ошибки и не пересказывает текст.
- **Падежи и согласование** — правит формы слов.

Стили переписывания: научный, официально-деловой, деловой требующий, деловой мягкий, простой, канцелярский. Повторное нажатие на уже выбранный «Простой» включает военный стиль: это тон доклада, а не описание действий.

Если поле пустое, подставляется начало «Бородина». Само нажатие на кнопку при этом не происходит.

Во время обработки исходный текст нельзя менять. «Остановить» прерывает свой запрос. Если модель занята другим человеком, текст встаёт в очередь: на экране видно, сколько текстов впереди и сколько примерно ждать. Очередь до 8 текстов.

Правки подсвечиваются: орфография красным, пунктуация синим, падеж зелёным, неуверенные места жёлтым. Убранная запятая отмечается синим подчёркиванием пробела. В скопированном тексте этой пометки нет.

Словарь терминов хранит написания, которые нельзя менять. Отзывы и идеи — отдельная страница. Оценка приложения и счётчик успешных переписываний стоят в шапке.

Выбор модели и загрузка Word (`.docx`) открываются ключом администратора. В `docker-compose.yml` ключ по умолчанию `local-admin`. Если сайт виден другим людям, замените `MODEL_ADMIN_KEY`.

Подробнее о экранах: [docs/возможности.md](docs/возможности.md).

## Что нужно заранее

- [Ollama](https://ollama.com/) с моделью `t-tech/T-lite-it-2.1:q4_K_M`, либо llama-server с OpenAI-совместимым адресом `/v1/chat/completions`.
- Для сайта в Docker — [Docker Desktop](https://www.docker.com/products/docker-desktop/).
- Для запуска из исходников — Python 3.12 или новее.

Модель на этом компьютере без видеокарты лучше держать в пределах примерно 9 млрд параметров.

## Установка и запуск в Docker

В папке проекта:

```bash
docker compose up -d --build
```

Сайт: http://localhost:8181.

Ollama должна быть запущена на этом же компьютере и слушать порт 11434. Адрес для контейнера уже указан: `http://host.docker.internal:11434`.

Остановка: `docker compose down`. Следующий запуск без пересборки: `docker compose up -d`.

В `docker-compose.yml` можно сменить адрес модели, имя модели и максимум контекста `LLM_NUM_CTX`. Короткий текст всё равно берёт окно меньше этого максимума. Чтобы ходить в llama.cpp, поставьте `LLM_BACKEND` в `llama` и укажите адрес llama-server.

Папка `data` рядом с compose хранит словарь, отзывы и счётчики. Её нет в git: она создаётся при работе.

## Установка и запуск из исходников

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8181
```

Без переменных окружения сайт обращается к `http://127.0.0.1:11434`. Чужие переменные вроде `LLM_BASE_URL` меняют адрес.

Проверка тестов:

```powershell
$env:PYTHONPATH = (Get-Location).Path
.\.venv\Scripts\python.exe -m unittest tests.test_corrections
```

## Программа Rewriter.exe

Готовый exe для Windows запускает тот же сайт и открывает браузер. Рядом с `Rewriter.exe` лежит `ollama.txt`: адрес Ollama, модель и порт. Сервер меняется в этом файле, заново собирать exe не нужно.

```text
address=http://127.0.0.1:11434
model=t-tech/T-lite-it-2.1:q4_K_M
port=8181
```

Если порт 8181 уже занят Docker, укажите в `ollama.txt` другой `port`. Чёрное окно консоли должно оставаться открытым. Папка `data` появится рядом с exe.

Сборка из исходников, если установлен PyInstaller:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\pyinstaller.exe --noconfirm --clean --distpath dist --workpath build exe\rewriter.spec
Copy-Item -Force .\exe\ollama.txt .\dist\ollama.txt
```

PyInstaller не входит в `requirements.txt`: офлайн-образ Docker его не ставит.

## Сервер без интернета

На флешку копируется папка [ofline](ofline) уже с собранным архивом `rewriter-images.tar.gz`. Как загрузить образ: [ofline/КАК_ЗАПУСТИТЬ.txt](ofline/КАК_ЗАПУСТИТЬ.txt). Сам архив в git не входит.

Модель на сервер переносится отдельно: [docs/перенос-t-lite-на-офлайн-сервер.md](docs/перенос-t-lite-на-офлайн-сервер.md). Большой словарь: [docs/большой-словарь.md](docs/большой-словарь.md).
